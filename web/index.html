      Overlay

      In-game overlay

      Off by default. Turning it on shows a transparent panel over the game — Star Citizen must run in Borderless Windowed for it to be visible. It arrives ready to move and resize; the 📌 pin button in its header puts it out of the way, so clicks reach the game instead. Unpin it from the tray icon, or with Ctrl+Alt+O. Ctrl+Alt+←/→ changes page and Ctrl+Alt+F goes fullscreen. The choice is remembered.

      Not available here: this dashboard is served by the bare server, which has no overlay window. Run QuantumWake.exe to get one.

      What the widget shows

      The widget is small and the dashboard is not, so it should carry a chosen few rather than everything. Changes reach a running overlay within a few seconds — no restart. Fullscreen ignores this and shows the lot.

      New versions

      Asks GitHub which release is newest and says so if it is ahead of this one. One request, carrying nothing but the request — no identifier, no version, no count of anything. Downloading and installing stays yours to do: the button opens the release page in your browser.

      Last wipe

      A data wipe resets what your account holds, so logs from before one describe an account you no longer have — adding those sales to this account's income makes a wrong number, not a bigger one. Sessions before this date are kept and still parsed, they are simply not counted. Moving the date back brings every one of them straight back.

      Wipes come at different depths — some take aUEC and leave the hangar, some clear inventories and leave balances. Tick only what this one actually took; everything left unticked keeps its whole history.

      Community commodity names

      Commodity names for your cargo, where each commodity trades, and the ship and item reference for the Fleet and Loadout pages — all from StarCitizenWiki / scunpacked-data. Enabling downloads a set of public files (~110 MB, kept as a few MB) into local app data. The app connects to the internet only when you ask it to, here, and never on its own. Disabling deletes the local copy.

      UEX live prices

      Crowd-sourced market prices from uexcorp.space — a third party, separate from the community dataset. Enabling fetches the current price table and shows best sell prices on the Market page. Like everything here: only on your click, never on a timer.

      Extra feeds. Narrower tables that each serve one page — take only what you need. Every one is a separate download on your click, and can be dropped again without touching the rest.

      Report your prices back. Every logged kiosk sale carries an exact unit price at a known terminal — the numbers UEX datarunners type in by hand. With your own UEX application token and secret key (from your UEX account), you can contribute them. Keys are stored in local app data only; every report is a button you press, previewed first.

      Log cache

      Sessions are cached and only changed logs are re-read. Force a full re-parse if something looks stale.

      About

      The goal is a frictionless companion for Star Citizen — one that gathers the useful information the game already writes down, and hands it back to fellow players without asking anything of them.

      It exists because I went looking for it and it was not there. There are good Game.log tools, but none of them was a whole product built around an org and the things I wanted to keep track of — so I built the one I had been looking for, and it is free for the community to use, and meant to stay that way.

      No account, no configuration, no upload. It reads Game.log and the backups beside it, resolves the names from your own copy of the game, and shows you what is there. Nothing is written to the game directory, and the app connects to the internet only when you ask it to — the optional datasets from the Settings page, and the version check if you turn that on. Never otherwise, and never on a timer.

      Questions

      Why is my pledged ship, armour or gun missing?

      Nothing that arrives in your account is written to Game.log. A pledge, a pack, a rental or anything bought on the website is simply there the next time you look, and the game says nothing about it. It appears here the first time you actually use it — fly the ship, wear the armour, move the item — because that is the first moment there is a line to read.

      Why are my totals lower than I expected?

      Sessions from before the last wipe are kept but not counted, because a wipe ends one account and starts another. Settings → Last wipe says how many sessions that is, lets you move the date, and lets you say what the wipe actually took — some reset aUEC and leave your hangar alone. Nothing is deleted: move the date back and it all returns.

      Where did the kill counter go?

      Removed, because it could only ever read zero. Star Citizen 4.9 does not write kill or vehicle-destruction lines to Game.log at all — checked line by line across every backup on this machine: not one. A counter pinned at zero reads as a broken feature rather than a missing one, so the honest thing is to say so here instead of showing it.

      The parser for those events is written and tested against the old format, sitting dormant. If CIG starts logging them again the counter comes back with it.

      Why does the map not show where I am, exactly?

      No player position is logged. Location is inferred from discrete signals — inventory requests, quantum routes, spawns — so the map is a topology, not a radar, and every estimate carries a confidence rather than pretending to a precision it does not have.

      The overlay will not let me click the game.

      Press its 📌 pin button and clicks pass straight through. To get it back, right-click the tray icon and untick Pin overlay, or press Ctrl+Alt+O. It arrives unpinned, so it can be dragged where you want it first.

      Does it touch the game, or my account?

      No. It reads Game.log and the backups beside it, and nothing is written to the game directory, no memory is read and nothing is injected. It connects to the internet only when you ask it to from the Settings page, never on its own.

      Does it phone home, or check for updates?

      It sends nothing about you, ever — no identifier, no usage, no statistics. It can look up whether a newer release exists, and only if you say yes: you are asked once, and Settings → New versions carries the switch and a Check now button. That look is one request to GitHub's public release feed, which carries nothing but the request. Nothing is downloaded or installed for you — you get a link to the release page.

      Something is wrong, or missing. Where do I say so?

      Please do. Message nekhron on Discord, or raise an issue at github.com/peans99/QuantumWake/issues. A log line that was parsed wrongly, with the line itself, is the most useful thing you can send.
