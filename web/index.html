Cargo trading

Volume, price and place come straight from the kiosk. What was in the boxes does not: the log names the commodity only by an internal id that nothing in the local install can resolve.

Name the cargo? The community keeps the id-to-name table as a public file (StarCitizenWiki / scunpacked-data). Enabling this downloads it once — the only network request this app will ever make — and it happens only if you press the button.

Equipment by slot

Settings

In-game overlay

Off by default. Turning it on shows a transparent panel over the game — Star Citizen must run in Borderless Windowed for it to be visible, and Ctrl+Alt+O toggles click-through. The choice is remembered.

Not available here: this dashboard is served by the bare server, which has no overlay window. Run QuantumWake.exe to get one.

Community commodity names

Cargo sales log the commodity as an id that nothing in the local install can resolve. The community keeps the id-to-name table as a public file (StarCitizenWiki / scunpacked-data). Enabling downloads it once into local app data — the only network request this app can make, and only on your click. Disabling deletes the local copy.

Log cache

Sessions are cached and only changed logs are re-read. Force a full re-parse if something looks stale.

About

The goal is a frictionless companion for Star Citizen — one that gathers the useful information the game already writes down, and hands it back to fellow players without asking anything of them.

No account, no configuration, no upload. It reads Game.log and the backups beside it, resolves the names from your own copy of the game, and shows you what is there. Nothing is written to the game directory, and no request leaves your machine.
