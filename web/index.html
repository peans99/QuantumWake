    Cargo trading

    Volume, price and place come straight from the kiosk. What was in the boxes does not: the log names the commodity only by an internal id that nothing in the local install can resolve.

    Name the cargo? The community keeps the id-to-name table as a public file (StarCitizenWiki / scunpacked-data). Enabling this downloads it once. The app connects to the internet only on your request, here or from the Settings page - never on its own.

    Settings

    In-game overlay

    Off by default. Turning it on shows a transparent panel over the game — Star Citizen must run in Borderless Windowed for it to be visible, and Ctrl+Alt+O toggles click-through. The choice is remembered.

    Not available here: this dashboard is served by the bare server, which has no overlay window. Run QuantumWake.exe to get one.

    Community commodity names

    Commodity names for your cargo, where each commodity trades, and the ship and item reference for the Fleet and Loadout pages — all from StarCitizenWiki / scunpacked-data. Enabling downloads a set of public files (~110 MB, kept as a few MB) into local app data. The app connects to the internet only when you ask it to, here, and never on its own. Disabling deletes the local copy.

    UEX live prices

    Crowd-sourced market prices from uexcorp.space — a third party, separate from the community dataset. Enabling fetches the current price table and shows best sell prices on the Market page. Like everything here: only on your click, never on a timer.

    Report your prices back. Every logged kiosk sale carries an exact unit price at a known terminal — the numbers UEX datarunners type in by hand. With your own UEX application token and secret key (from your UEX account), you can contribute them. Keys are stored in local app data only; every report is a button you press, previewed first.

    Log cache

    Sessions are cached and only changed logs are re-read. Force a full re-parse if something looks stale.

    About

    The goal is a frictionless companion for Star Citizen — one that gathers the useful information the game already writes down, and hands it back to fellow players without asking anything of them.

    No account, no configuration, no upload. It reads Game.log and the backups beside it, resolves the names from your own copy of the game, and shows you what is there. Nothing is written to the game directory, and the app connects to the internet only when you ask it to, from the Settings page — never on its own.
