How the shipped profile is laid out

Home shows Flight, Operations, Resources and Pilot. Top buttons 1–5 follow the visible menu: choose a category, then a screen. On a screen, those buttons switch between pages in the same category. Unused options stay blank.

15 BACK moves up one level; 13 HOME returns to the cockpit menu. 10 MORE opens secondary readings; Back returns to the overview first. 14 UP / 12 DOWN scroll or select a checklist task. 8 DONE is available on Checklist: press once to arm, again to mark the task. It updates your plan, not the game.

Saved custom assignments are kept. Choose Restore defaults above and Save layout to adopt the menu profile. You can also bind direct page shortcuts, category menus, Home and Back yourself. Keep a Home or Back binding accessible when using a frame.

The four rocker switches report as buttons 21–28, and which rocker is which number is not something a datasheet answers — so they ship unassigned. Press one, watch the tester name its number, and bind it above.

USB detection uses Windows joystick slots 1–16 and the default F16 MFD names. If a device is missing, check the Thrustmaster driver and close any T.A.R.G.E.T. profile that replaces the devices with a virtual controller. Duplicate MFD numbers must be changed in the Thrustmaster control panel.

MFD mode is optional. Your regular overlay has its own settings.
